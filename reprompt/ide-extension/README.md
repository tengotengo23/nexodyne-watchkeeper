# Re-Prompt Extension for Antigravity IDE, VS Code & Claude Code

Type rough ideas in an overlay composer right alongside or over **Antigravity Chat** and **Claude Code** — Re-Prompt automatically transforms them into crisp, detailed, dual-readable instructions that are effortless for both the AI and the human prompter to read.

## Features

- **Status Bar Launcher**: Click **✨ Re-Prompt** in the bottom-right status bar at any time.
- **Overlay Composer (`Ctrl+Alt+R` / `Cmd+Alt+R`)**: Opens a theme-matched composer panel with **Readable**, **Edit**, and **Compare** views, target toggle (**Antigravity** / **Claude Code** / **General**), modes (**Balanced**, **Deep Spec**, **Bug Fix**, **Refactor**, **Concise**), and quick refinements.
- **Quick Floating Overlay (`Ctrl+Alt+Shift+R` / `Cmd+Alt+Shift+R`)**: Pops a lightweight floating input bar right over the IDE chat window without shifting your layout.
- **Zero-Config Default + Multi-Provider**: Uses your local `agy` CLI out of the box, or configure `claude` CLI, Gemini API, Anthropic API, OpenAI/Ollama, or Offline Template in Settings.
- **1-Click Dispatch**: Send directly to Antigravity Chat or focus & copy straight to Claude Code.
