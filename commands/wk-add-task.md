Run the Watchkeeper /wk command family:

```bash
node "${CLAUDE_PLUGIN_ROOT}/bin/wk.mjs" task $ARGUMENTS
```

Show the output as printed. Do not start agy or Gemini.

Alias of `/wk task "..."`. Run it inside a git repository.
